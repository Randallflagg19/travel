# Travel: предложения по превью ссылок и social media presence

Обновлено 7 октября 2026 года. Необязательный backlog по результатам
проверки `https://staging.tapir.su/` в [OpenGraph.to](https://www.opengraph.to/).
Пользователь доволен текущим видом карточки в проверочном сервисе;
улучшения ниже выполнять по желанию и отдельному согласованию.
Оценка сервиса не является критерием готовности релиза.

## Что уже сделано

- Ветка `staging-infrastructure`, коммит
  `6c4bd05596ab034a66fb9eb763a8e46aad556287` опубликован на staging.
- `metadataBase` больше не содержит старый Vercel-домен. Сборки получают
  `NEXT_PUBLIC_SITE_URL`: `https://staging.tapir.su` для staging,
  `https://www.tapir.su` для production.
- OG/Twitter используют выбранную широкую картинку с тапиром: PNG
  1734 × 907, 2 052 233 байта. Next.js определяет URL, тип и размеры
  из файлов `frontend/src/app/opengraph-image.png` и `twitter-image.png`;
  подписи находятся в соответствующих `.alt.txt`.
- Проверены lint, обе сборки, HTML главной, входа и регистрации.
  Публичная картинка staging скачана целиком и совпадает с исходником.
- OpenGraph.to показывает новую картинку, заголовок и описание, в том числе
  в имитации карточки Telegram. Это не проверка настоящего Telegram.
- Эти изменения **не опубликованы на production**. Пользователь решил
  не переносить их туда до подтверждения полезного визуального результата.

## Открытый вопрос Telegram

В реально отправленных сообщениях картинка пока не появилась. В отдельных
попытках отображались заголовок и описание, в других — только ссылка.
Смена браузера и ответ бота обновления превью об успехе результата не дали.
Причина не установлена; кэш не признан доказанной причиной.

Внешние проверки с Mac иногда завершались TLS-тайм-аутом при установленном
TCP-соединении. Через текущее VPN-соединение последующая проверка получила
всю картинку за 1,45 секунды; локальный HTTPS через Nginx на VPS также работал.
Эти результаты не устанавливают маршрут и доступность для серверов Telegram.
Запросы с подставленным TelegramBot User-Agent не считать запросами Telegram.
Пустой 45-секундный захват пакетов не дал вывода: попадание пользовательской
отправки в интервал захвата не подтверждено.

Критерий завершения: ожидаемая картинка, заголовок и описание видны
в реально отправленном сообщении Telegram. Повторные проверки пока отложены.

## Предложения на будущее

Исходный отчёт: оценка 64, 3 предупреждения и 12 советов; HTML около 15 КБ,
время ответа в этой проверке 722 мс. Это один замер и рекомендации сервиса,
а не доказанные причины сбоя Telegram.

| Пункт | Предлагаемое действие и приоритет |
| --- | --- |
| Размер и вес картинки | При необходимости подготовить копию 1200 × 630 в JPEG, сравнить качество и вес. Сохранить исходный PNG. Проверять на staging как отдельный эксперимент; текущие пропорции почти совпадают с 1200 × 630, отчёт не доказывает недопустимость 1734 × 907. |
| Canonical URL | Определить политику канонических адресов для страниц и query-параметров; отдельно решить индексацию staging. Затем добавить корректные canonical по маршрутам, не назначать всем страницам главную автоматически. |
| H1 | Проверить реальный DOM и исходный HTML: сервис сообщил, что H1 не найден. При необходимости добавить осмысленный основной заголовок без нарушения дизайна; не считать отсутствие H1 причиной пропажи OG-картинки. |
| Apple touch icon | Подготовить и подключить иконку 180 × 180 для добавления сайта на домашний экран iOS. Не относится к картинке Telegram. |
| og:locale | Добавить `ru_RU`, если русский остаётся основным языком сайта. |
| Название и описание | Пересмотреть текст только ради ясности для читателя. Советы о коротких title, description и meta description не требуют растягивать «Tapir Travel» до заданного числа символов. |
| twitter:site | Добавлять только при наличии реального аккаунта проекта. Создавать аккаунт ради валидатора не нужно. |
| JSON-LD | При появлении задачи поисковой индексации описать реальные сущности сайта подходящей разметкой; не добавлять фиктивные рейтинги и данные. |
| theme-color | Выбрать цвет панели мобильного браузера под оформление Travel и подключить metadata. |
| Favicon 32 × 32 и SVG | При необходимости подготовить варианты существующего знака и проверить вкладки браузеров. Существующий favicon сервис уже отображает. |
| Web app manifest | Добавлять в рамках отдельного решения об установке сайта/PWA, а не ради балла отчёта. |
| Время ответа | Собрать повторные замеры с разных сетей и разделить DNS/TCP/TLS/ответ приложения. Не вводить CDN и не менять сервер по единственному замеру 722 мс. |

## Порядок работы, если вернёмся к улучшениям

1. Выбрать конкретный пункт и согласовать изменение; не исправлять весь отчёт
   за один подход и не смешивать SEO с расследованием доступности Telegram.
2. Подготовить локальное изменение, проверить сборку и итоговый HTML.
3. После согласования опубликовать через frontend staging GitHub Actions.
4. Проверить карточку в сервисе и отдельно фактическую отправку в Telegram.
5. Production публиковать только после отдельного согласования и приёмки.

Справка по файловым OG/Twitter metadata:
[Next.js](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/opengraph-image).
