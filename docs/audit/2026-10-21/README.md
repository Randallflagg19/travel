# Материалы проверки

Сессия начата 21 октября, завершена 22 октября 2026 по Москве.

JSON — исходные результаты публичных read-only замеров Chromium и локальных browser probes. В них нет токенов настоящих пользователей; адреса медиа публичные. Cold означает новый browser context, а не очищенный CDN. Ограниченный сетевой прогон завершён до окончания фонового PNG: его сумму байтов нельзя считать полным весом страницы.

- desktop-cold.json, mobile-cold.json, mobile-warm.json, mobile-slow-cold.json — сеть, размеры DOM, LCP/CLS за окно наблюдения.
- behavior.json — четыре воспроизведённых дефекта на фиктивном API.
- public-probe.cjs — публичный сетевой замер без входа и записи данных.
- behavior-probe.cjs — локальная проверка ошибок; ожидает frontend на 127.0.0.1:3000, собранный с NEXT_PUBLIC_API_URL=/api-proxy. Все API-запросы подменены.

Запуск из корня: node docs/audit/2026-10-21/public-probe.cjs либо behavior-probe.cjs. Нужны frontend/node_modules и установленный Chromium Playwright. Новые отчёты записываются во временный каталог, сохранённые результаты не перезаписываются. Скрипты — инструменты аудита, не замена регрессионным тестам после исправлений.
